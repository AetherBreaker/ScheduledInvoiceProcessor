If container won't start:
1. Check logs: docker-compose logs
2. Verify secrets exist: ls -la secrets/
3. Check secret files are valid JSON:
   cat secrets/db-key.json | python3 -m json.tool

If you see "permission denied" errors:
1. Make sure Docker Desktop is running
2. Verify you're in the project directory

If Google Sheets connection fails:
1. Verify db-key.json is in ./secrets/
2. Check logs for specific error message
3. Ensure service account has access to spreadsheet

If logs aren't appearing in ./logs/:
1. Container might still be starting (wait 30 seconds)
2. Check container is running: docker ps
3. Check volume mounts: docker inspect scheduled-order-middleman
